怎么读这张表　「正文截稿」是按北京时间算的，177 个会议的原始时区是 AoE / UTC−12，折算后要 +20 小时，174 个会议的截稿日因此顺延了一天，别拿 ccfddl 上的日期直接对照。多轮会议过了一轮会自动切到下一轮。
「官网核查」为已核实的行，参会形式与投稿上限来自官方页面原文；2027 CFP 未发布表示官网还没有 2027 征稿说明，字段一律留「待确认」，没有用往届口径冒充。
「投稿上限」只填官方明文写出的数字，没写就是「不限」，已统一成「N 篇/届、/轮、/年」，点表头可按篇数排序。ACL / NAACL / EACL / COLING 走 ARR 滚动审稿，主表里的日期是 commit 节点，真实投稿看 ARR cycle。
「新人作者条款」专指首投者会踩的坑：审稿义务/互惠审稿、首投配额、是否强制挂资深作者、投稿账号门槛、学生新人通道。点顶部「有新人条款」可只看这些会；「无专属条款」是查过确实没有，不是没查。
