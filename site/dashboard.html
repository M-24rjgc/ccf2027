怎么读这张表

  • 时间都是北京时间。— 个会议的原始时区是 AoE / UTC−12，折算要 +20 小时，— 个会议的截稿日因此顺延一天，别拿 ccfddl 上的日期直接对照。多轮会议过了一轮自动切到下一轮。
  • 摘要截稿往往早一周。有独立摘要注册的会议，在截稿日期下方单独标出，没注册摘要就交不了正文。
  • 「已核实」表示参会形式与投稿上限来自官方页面原文；「2027 CFP 未发布」表示官网还没有 2027 征稿说明，相关字段留「待确认」，不拿往届口径冒充。
  • 投稿上限只写官方明文给出的数字，没写就是「不限」。ACL / NAACL / EACL / COLING 走 ARR 滚动审稿，表里是 commit 节点，实际投稿看 ARR cycle。
  • 新人作者条款专指首投者容易踩的坑：审稿义务、首投配额、强制资深作者、账号门槛、学生通道。「无专属条款」是查过确实没有，不是没查。
  • 录用率取 ccfddl 汇总的往届数据（MIT 许可），仅供参考。
